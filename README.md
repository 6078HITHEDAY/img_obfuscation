# 图片混淆

纯前端、零依赖的图片混淆与还原工具。运算只在浏览器本地完成，**不会上传到任何服务器**。

## 本地运行

```bash
npm run serve
# 或：python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

也可直接打开 `index.html`（`file://` 下部分浏览器会限制剪贴板粘贴）。

```bash
npm test          # 等价于 bash tests/verify.sh（需 python3+Pillow、node）
```

## 它是什么

把图片打乱成看不出内容的杂色，用相同方式与密码再还原。适合「随手点开看不到原图」的场景，**不是加密**：知道参数的人都能还原。

常用流程：拖入 / 点选 / `Ctrl+V` 粘贴 → 选方式与密码 →「混淆」→ 下载 PNG → 再拖入同一张 PNG「还原」。还原成功时状态栏会提示与原图逐像素一致。

参数会记在 `localStorage`；支持浅色 / 深色主题。无构建、无后端：改完静态文件刷新即可。

## 五种模式

| 方式 | 参数 | 说明 |
|---|---|---|
| 小番茄 `tomato` | 4 位数字（默认 `0000`） | Gilbert 曲线 + 黄金分割位移；可与原版小番茄互通（见下） |
| 蛇形扫描 `serpentine` | 任意文本种子 | 逐行往返遍历后整体位移 |
| 分块打乱 `blocks` | 任意文本种子 | 约 32×32 块重排 + 块内旋转；不足一块的边缘不动 |
| 行列错位 `rows` | 任意文本种子 | 每行右移、每列下移 |
| 像素扰动 `xor` | 任意文本种子 | RGB 与伪随机流异或 |

小番茄密码：前两位为迭代轮数（`00` 按 1 轮），第 3 / 4 位为右 / 下边缘复制填充列数、行数。有填充时密图会略大几像素。

与原版小番茄**逐字节**互通时，调用需 `ImgObf.process({ marker: false, ... })`（本页默认会写末行标识，高度 +1）。

## 末行标识与自动识别

混淆（加密）默认在图像**最底部追加 1 行**元数据：

- 位置：最后一行；上方混淆像素不变
- 内容：`IOBF` + 版本 + 模式 + 可选种子（UTF-8）+ CRC32；按 RGB 打包，A=255
- 载入时：`ImgObf.inspect(data, w, h)` 能读出则自动填入方式（及能写入的密码）；页面可直接点「还原」
- 无标识的旧图 / 原版小番茄图：`inspect` 为 `null`，行为与从前一样，需手动选模式
- 解密时若检测到合法标识，会先裁掉末行再运算；也可用 `mode: 'auto'`

宽过窄（&lt; 4）时不写标识；种子过长放不下时只写模式。

## 文件结构

```
index.html   页面（放入 → 参数 → 处理 → 结果）
base.css     站点壳与主题变量
tool.css     本页样式
algo.js      算法：ImgObf.process / inspect（可 Node require）
app.js       交互：读图、标识自动填参、下载
tests/       回归测试
deploy/      nginx 子路径部署示例
```

## 测试覆盖

1. Python 参考实现 vs `algo.js`（小番茄，`marker: false`）逐字节比对  
2. 五种模式多尺寸往返一致  
3. 错误 / 非法密码行为  
4. 末行标识写入、`inspect`、`mode:'auto'`，以及无标识兼容  
5. 1920×1080 加解密耗时打印  

## 部署

纯静态文件。例如挂到站点子路径 `/hunxiao/`：把本目录放到对应目录，可参考 `deploy/nginx-example.conf`。

改前端后请同步升高 `index.html` 里 `base.css` / `tool.css` / `algo.js` / `app.js` 的 `?v=`，避免缓存旧资源。

## 限制（摘要）

- 必须用 PNG 或原始文件传输；微信 / QQ 等重压缩会破坏像素，无法还原  
- 上限约 2400 万像素；主线程同步处理，大图可能短暂卡顿  
- 透明通道在画布预乘下，透明区颜色可能有差异  
- 未实现「大番茄 v3」等扩展格式
