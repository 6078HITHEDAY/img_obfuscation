# 图片混淆 / Image Obfuscation

纯前端、零依赖的图片混淆与还原工具。图片只在浏览器画布里处理，**不会上传到任何服务器**。

线上地址：<https://tool.myflycat.cn/hunxiao/>

## 特性

- 五种可逆的混淆方式：小番茄、蛇形扫描、分块打乱、行列错位、像素扰动
- 拖入 / 点选 / `Ctrl+V` 粘贴三种导入方式
- 混淆与还原各一个按钮，结果导出无损 PNG
- 混淆后再还原会在状态栏提示「✓ 与原图逐像素一致」，方便自查
- 深色模式、手机宽度适配、参数自动记忆（localStorage）
- 无构建、无后端、无第三方依赖：改完文件刷新即可

## 快速开始

```bash
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

也可以直接双击 `index.html`（`file://` 下个别浏览器会限制剪贴板粘贴）。

## 使用

1. 把图片拖进页面（或点选 / 粘贴）
2. 选混淆方式，填密码或种子
3. 点「混淆」→「下载 PNG」
4. 要还原时，把 PNG 重新拖进来，选**同样的方式与密码**，点「还原」

选错方式或密码不会报错，只会得到另一张看不懂的图。

## 五种方式

| 方式 | 参数 | 说明 |
|---|---|---|
| 小番茄 `tomato` | 4 位数字密码（默认 `0000`） | Gilbert 曲线遍历 + 黄金分割位移；与原版小番茄互通 |
| 蛇形扫描 `serpentine` | 任意文本种子 | 逐行往返遍历后整体位移，横向条纹状 |
| 分块打乱 `blocks` | 任意文本种子 | 32×32 整块重排 + 块内随机旋转，边缘不足一块的像素不动 |
| 行列错位 `rows` | 任意文本种子 | 每行右移、每列下移，位移量由种子决定 |
| 像素扰动 `xor` | 任意文本种子 | 逐像素 RGB 与伪随机流异或，呈彩色噪点 |

小番茄密码的四位含义：前两位是迭代轮数（`00` 按 1 轮算），第 3 位是右侧复制填充列数，第 4 位是下侧复制填充行数。带填充时混淆图会变大几像素，还原会先裁掉再反置换。

## 算法说明

### 小番茄

1. 生成覆盖 `W×H` 的广义 Hilbert（Gilbert）曲线，每个像素恰好访问一次；
2. 沿曲线整体循环位移 `offset = round(0.618033988749895 × W × H)`；
3. 映射方向是 `perm[dst] = src`；密码前两位 `n>1` 时把该置换连做 `n` 次（二进制幂实现）；
4. 加密后按密码第 3、4 位在右侧/下侧复制边缘像素做填充；解密先裁掉再反置换。

改这块时注意三件事，否则会跟原版小番茄对不上：

- 曲线递归里的整除必须是 `Math.floor(ax / 2)`。Python 的 `//` 对负数是向下取整，JS 的 `|0` 是向零截断，递归到负方向时会走错分支；
- 位移量是 `round(φ × N)`，不是老网页版用的 `round(φ × (N-1))`；
- 映射方向 `perm[dst] = src`，解密是 `perm[src] = dst`（互为逆置换）。

### 其它四种

都建立在同一套「排列 + 种子」思路上，具体实现见 `algo.js` 里对应函数。它们只保证本工具自身的往返一致，不与外部工具互通。

## 测试

```bash
npm test          # 等价于 bash tests/verify.sh
```

需要 `python3`（带 Pillow）和 `node`。测试内容：

1. 用 Python 参考实现（原版小番茄 JS 的直译）对 7 种尺寸 × 2 组密码生成密文，与 `algo.js` 的输出**逐字节比对**；
2. 五种方式在 9 种尺寸、多个种子下加密后解密，要求与原数据完全一致；
3. 错误密码必须解不出原文、非法密码必须报错；
4. 1920×1080 的加解密耗时打印（用于观察性能回归）。

## 部署

子路径部署（当前线上就是这样）：把本目录文件放到 `/var/www/tools/hunxiao/`，站点 root 指向 `/var/www/tools` 即可，nginx 片段见 `deploy/nginx-example.conf`。

纯静态，没有进程要重启。改完前端后把 `index.html` 里四处 `?v=`（`base.css`、`tool.css`、`algo.js`、`app.js`）一起升版本号，避免浏览器吃旧缓存。

## 已知限制

- **混淆不是加密**：知道方式与密码的人都能还原，只防「随手点开就看到」和机器直接读图；
- 图片经微信 / QQ 等二次压缩后像素会变，**解不回来**，必须用 PNG 或原始文件传输；
- 上限 2400 万像素（再大浏览器内存吃不消），处理在主线程同步进行，超大图会有短暂卡顿；
- 透明像素的 RGB 在画布预乘/反预乘过程中可能归零，透明区域颜色可能有差异（Chrome 实测整图往返 diff=0，其它浏览器未逐一验证）；
- 目前只兼容小番茄 legacy 格式，未实现「大番茄 v3」（底部条码、尺寸元数据、抗缩放、自愈备份）；
- 没有批量处理、拖动分割对比、分享链接带参数。
