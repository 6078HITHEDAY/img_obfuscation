# 图片混淆

纯前端、零依赖的图片混淆与还原工具。运算只在浏览器本地完成，**不会上传到任何服务器**。

## 本地运行

```bash
npm run serve
# 或：python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

也可直接打开 `index.html`（`file://` 下部分浏览器会限制剪贴板粘贴）。

```bash
npm test          # 等价于 bash tests/verify.sh（需 python3+Pillow、node）
```

## 它是什么

把图片打乱成看不出内容的杂色，用相同方式与密码再还原。适合「随手点开看不到原图」的场景，**不是加密**：知道参数的人都能还原。

常用流程：拖入 / 点选 / `Ctrl+V` 粘贴 → 选方式与密码 →「混淆」→ 下载 PNG → 再拖入同一张 PNG，确认密码后「还原」。

若密图带有本工具写入的末行标识，载入时会**自动填入方式**；密码仍需手输或沿用本地记忆，不会从图里读出。

参数记在 `localStorage`；支持浅色 / 深色主题。无构建、无后端：改完静态文件刷新即可。

## 五种模式

| 方式 | 参数 | 说明 |
|---|---|---|
| 小番茄 `tomato` | 4 位数字（默认 `0000`） | Gilbert 曲线 + 黄金分割位移 |
| 蛇形扫描 `serpentine` | 任意文本种子 | 逐行往返遍历后整体位移 |
| 分块打乱 `blocks` | 任意文本种子 | 约 32×32 块重排 + 块内旋转；不足一块的边缘不动 |
| 行列错位 `rows` | 任意文本种子 | 每行右移、每列下移 |
| 像素扰动 `xor` | 任意文本种子 | RGB 与伪随机流异或 |

小番茄密码：前两位为迭代轮数（`00` 按 1 轮），第 3 / 4 位为右 / 下边缘复制填充列数、行数。

**与原版小番茄工具互通**：页面勾选「兼容原版」（或 API 传 `marker: false`），混淆时**不**追加末行标识。默认不勾选时会写标识，原版工具解不开。

## 末行标识与自动识别

混淆（加密）默认在图像**最底部追加 1 行**元数据：

- 位置：最后一行；上方混淆像素不变
- 内容：`IOBF` + 版本 + **模式** + CRC32（按 RGB 打包，A=255）
- **不存种子 / 密码**；自动识别只填方式
- 载入：`ImgObf.inspect(data, w, h)` → `{ mode, version }` 或 `null`
- 无标识的旧图 / 原版小番茄图 / 勾选兼容原版输出的图：需手动选模式
- 解密若检测到合法标识，先裁掉末行再运算；也可用 `mode: 'auto'`（仍需调用方提供密码）

重新导入带标识的密图再还原时，页面会提示「已还原（方式来自标识）」，不会拿密图尺寸去和「原图」做逐像素比对。

## 文件结构

```
index.html   页面（放入 → 参数 → 处理 → 结果）
base.css     站点壳与主题变量
tool.css     本页样式
algo.js      算法：ImgObf.process / inspect（可 Node require）
app.js       交互：读图、标识自动填方式、兼容原版勾选、下载
tests/       回归测试
deploy/      nginx 子路径部署示例
```

## 测试覆盖

1. Python 参考实现 vs `algo.js`（小番茄，`marker: false`）逐字节比对  
2. 五种模式多尺寸往返一致  
3. 错误 / 非法密码行为  
4. 末行标识只存模式、`inspect` 不暴露种子、`mode:'auto'` + 用户种子往返、无标识兼容  
5. 1920×1080 加解密耗时打印  

## 部署

纯静态文件。例如挂到站点子路径 `/hunxiao/`：把本目录放到对应目录，可参考 `deploy/nginx-example.conf`。

改前端后请同步升高 `index.html` 里 `base.css` / `tool.css` / `algo.js` / `app.js` 的 `?v=`，避免缓存旧资源。

## 限制（摘要）

- 必须用 PNG 或原始文件传输；微信 / QQ 等重压缩会破坏像素，无法还原  
- 上限约 2400 万像素；主线程同步处理，大图可能短暂卡顿  
- 透明通道在画布预乘下，透明区颜色可能有差异  
- 未实现「大番茄 v3」等扩展格式
